Before you buy

  1. Verify the exact ESRB / North American edition and seller photos.
  2. Confirm whether the full base game is physically on the card, a Game-Key Card, or a code in a box.
  3. Check separate DLC, day-one patches, and whether Switch 2 Edition cards run on Switch 1.
  4. Compare delivered price, sealed condition, sold-listing values, and game quality.
